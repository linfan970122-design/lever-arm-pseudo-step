## Table 6. C++ patch vs `fig/gate.py` (live chain, approximate cross-check)

**A frame-exact cross-check is not achievable on the live chain**: the gate input is the filter
yaw the node looks up from tf itself, which cannot be recorded outside the node; the only proxy
is the 30 Hz `/odometry/filtered` interpolated to the fix timestamps.

| run | fixes offered | C++ published | Python published | publish decisions disagreeing | direction | within <0.5 s of a filtered dropout |
|---|---|---|---|---|---|---|
| GATED q=0.06 | 9755 | 9746 | 9612 | 134 (1.4 %) | all Python stricter | 89 (66 %) |
| GATED q=1e-5 | 9759 | 9692 | 9639 | 61 (0.6 %) | 57 stricter / 4 looser | 44 (72 %) |

The p95 difference in the heading used is 0.53° / 0.27°. The disagreements are **all or almost all
the Python side being stricter**, and two thirds of them fall where the recorded
`/odometry/filtered` has a gap >0.1 s -- an inaccurate proxy input, not a different rule.
The earlier frame-exact result on the raw heading stream (0 disagreements over 364 799 frames
× 3 variants) still holds; no line of the C++ was changed here.
